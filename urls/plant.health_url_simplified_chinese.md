# da:922
### 你看到的现象
整株萎蔫、叶片全部干枯或脱落，茎干空心、发黑或易折，盆土长期潮湿或彻底干透后不再回弹。轻触就碎，或多年未见新芽。

### 是什么
植株已丧失生命活动的状态。与“休眠”不同，细胞组织已经不可逆受损，不再具备萌发能力。

### 是否属于正常现象
不是自然过程，但常见于长期护理失衡（严重缺水/积水、极端温差、根系腐烂、药害等）之后。也可能是寿命到期（如一年生草本）。

### 可能原因
- 长期严重缺水或高温暴晒，组织失水致死。  
- 长期积水、根腐，根系无法供水。  
- 冬季极冷或夏季极热的极端温度伤。  
- 严重虫害或病害导致全株衰亡。  
- 药害/肥害，浓度或频次过高。  
- 移栽损伤过重、主干/根颈机械断裂。

### 如何确认
- **刮皮测试**：用指甲轻刮枝条表皮，若内层仍有绿色与湿润感，尚有生机；若完全褐色干燥，多半死亡。  
- **根系检查**：轻脱盆，健康根坚韧、白或淡黄；死亡根发黑、糜烂、有异味。  
- **折断测试**：枝条一折即断且呈空心或粉碎，生命迹象极低。  
- **观察基部**：根颈/块茎若坚实，仍可能有腋芽再萌。

### 你可以做什么
1. **判定可救性**：若仍有绿色层或健康根，剪除全部枯死部位，保留健段。  
2. **调整基质与浇水**：更换疏松排水土，彻底浸润后排尽多余水；此后遵循“见干见湿”。  
3. **稳定环境**：明亮散射光、22–26°C、相对湿度40–60%，避免暴晒与冷风。  
4. **减负促生**：去花去果、重度修剪，降低蒸腾，等待基部或根颈处萌芽。  
5. **慎施肥药**：萌芽前不施或仅用极稀薄平衡肥；暂缓一切强刺激喷施。  
6. **若完全确认死亡**：妥善处理盆土（病害风险时丢弃或高温消毒），花盆清洗消毒再用。

### 预防要点
规律浇水、合适光照与温度、定期检查根系与排水；新手可用指测或称重法判断浇水时机。对敏感品种，优先少量多次的保守策略。

# da:921
### 你看到的现象
叶尖或叶缘干枯、卷曲，出现褐色“烧边”；新叶薄而脆；花苞易干瘪脱落。冬季供暖或夏季空调房尤其明显。

### 是什么
空气湿度长期偏低引起的失水性胁迫。许多热带观叶植物原生环境湿度高，一旦室内相对湿度低于40%，就容易出现叶尖焦枯。

### 是否属于正常现象
不是疾病，但很常见的环境问题。通过提升局部湿度与优化浇水节律，可明显改善。

### 可能原因
- 供暖或空调长期运行，湿度降至30–40%以下。  
- 强烈日照与高温叠加，加速叶片蒸腾。  
- 根系供水受限（小盆、土团疏水），放大症状。  
- 风口直吹（空调/风扇），表面水分迅速带走。

### 如何确认
- **湿度计**：相对湿度常在40%以下。  
- **症状分布**：多从叶尖、老叶开始，呈均匀干焦，而非不规则病斑。  
- **盆土状况**：若盆土并不长期干透但叶仍焦，多为空气干燥而非单纯缺水。

### 你可以做什么
1. **增加局部湿度**：植物聚摆成小群；使用加湿器，目标湿度40–60%；砾石托盘增湿（底孔不浸水）。  
2. **优化浇水**：浇至盆底刚有水珠流出即停，倒空托盘；对疏水土，先少量多次润湿或温水缓慢浇透。  
3. **调整位置与风**：远离空调、暖气直吹；夏季用透光纱帘削弱炙热直射。  
4. **叶片护理**：偶尔湿布擦拭积尘提升气孔交换；不建议频繁喷雾淋湿叶面以免水渍或病害。  
5. **对敏感品种**（蕨类、竹芋类）：优先“加湿器+散射光”的组合。

### 预防要点
季节交替提前测湿；供暖期开机即开加湿器；定期修剪枯尖，避免持续消耗。稳定、温和的湿度管理比短时强措施更有效。

# da:838
### 你看到的现象
叶片出现孔洞、缺刻、锯齿状或不规则撕裂；嫩叶被咬缺，叶缘参差；某些叶背可见啃食痕与粪粒。

### 是什么
由咀嚼式口器的动物造成的取食损伤，常见于毛虫、甲虫幼虫、鼻涕虫/蛞蝓、蝗类等。与“吸汁型”的点状、褪色、卷曲不同，咀嚼型直接“吃掉”叶组织。

### 是否属于正常现象
属于真实问题，但多数轻微可控，不会致命；对幼苗、新叶或结实时影响更大。

### 可能原因
- 夜行性软体动物或昆虫取食。  
- 盆土带入的幼虫在根际化蛹羽化后上叶取食。  
- 室外或阳台虫源多、光照潮湿条件适合繁殖。

### 如何确认
- **夜间巡查**：晚间用手电查看叶背、盆沿、墙角，常能发现虫体。  
- **痕迹判断**：边缘整齐的大口缺多为蛞蝓/蜗牛；叶中穿洞或不规则锯口多为毛虫/甲虫。  
- **粪粒与银色爬行痕**：蛞蝓留银白黏痕；毛虫留颗粒状粪便。  
- **诱捕**：黄/蓝粘板可捕部分成虫；啤酒陷阱对蛞蝓有效。

### 你可以做什么
1. **物理与生态手段为先**：人工摘除可见虫卵与虫体；夜间夹捕蛞蝓；重伤叶剪除以减少引诱。  
2. **环境管理**：保持通风与清洁，减少隐藏点；浇水在早上进行，晚间避免潮湿滞留；盆面铺干净粗砂或珍珠岩降低蛞蝓舒适度。  
3. **生物/低风险用药（按标签）**：可选苦楝油或皂剂喷雾覆盖叶正反面；对蛞蝓可用铁盐诱杀颗粒，注意宠物安全；轮换使用避免高频。  
4. **保护天敌**：避免在封闭阳台长期使用广谱强杀虫剂，以免破坏生态平衡。

### 预防要点
新植物隔离观察1–2周；定期翻看叶背；夜间不留潮湿杂物。轻伤不必恐慌，恢复期保证光照与营养即可。

# da:984
### 你看到的现象
花朵逐渐失色、萎蔫、凋落；花梗转黄变软；不开新花或花序走向尾声。叶片总体仍健康。

### 是什么
自然的花期结束。多数观花植物开花属于阶段性生殖生长，花朵生命周期有限，凋谢后养分回流到植株。

### 是否属于正常现象
是自然过程，不属于疾病。无需担忧，也无需急用药。

### 可能原因
- 花期已到尾声或品种花期本就较短。  
- 花后未及时修剪，能量被结籽消耗。  
- 管理因素（光照不足、养分偏少）影响再次成花，但不影响已开的花自然凋谢。

### 如何确认
- 花瓣失去光泽、变薄、下垂，花基部易脱落；  
- 植株叶片无明显病斑或成片枯萎；  
- 品种规律：有的季节性一次开花，有的可反复开花（需养护到位）。

### 你可以做什么
1. **及时修剪残花**：在第一片健康叶位上方剪掉残花与花梗，避免结籽消耗。  
2. **花后恢复**：提供明亮散射光或每日数小时日照；水分“见干见湿”；花后2–3周补低氮平衡肥，促新梢与根系。  
3. **二次成花准备**：修整株形、保证通风；给予昼夜温差与适度光照强度；对需休眠的品种，顺应季节节律。

### 预防要点
了解品种花期与习性；按需补光/控温；不要把“花谢”误判为病。把花后管理做好，下一轮会更出色。

# da:1118
### 你看到的现象
叶片出现针尖大小褪色点、发黏的蜜露、叶背细小昆虫或棉絮团；叶卷曲、发黄、生长停滞；附近表面出现黑色霉层。

### 是什么
吸汁型害虫造成的危害，常见有蚜虫、粉虱、介壳虫、粉蚧、红蜘蛛等。它们用口器刺吸汁液并分泌蜜露，引发煤污。

### 是否属于正常现象
是真实虫害，需要尽快控制，但以温和、渐进的方式处理即可，不必恐慌。

### 可能原因
- 新购植株或花束带入虫源，未隔离；  
- 环境温暖干燥、通风差，利于繁殖；  
- 氮肥偏高、嫩梢多，易招虫。

### 如何确认
- **叶背放大观察**：可见移动小虫、网点或棉絮；  
- **蜜露与煤污**：叶面、窗台有粘液并长黑霉；  
- **拍打试验**：轻拍叶片，白色小飞虫飞起多为粉虱；  
- **蛛网**：细密丝网伴叶背黄白小点多为红蜘蛛。

### 你可以做什么
1. **先洗后药**：温和水流冲洗叶正反面与枝条，随后擦干；对粉蚧/介壳，用蘸酒精的棉签点拭。  
2. **低风险用药（严格按说明）**：肥皂/皂苷/矿物油/苦楝油轮换喷布，覆盖叶正反面与枝条分叉处；连续2–3次，间隔7–10天。对红蜘蛛提高喷雾频率与湿度，并用针对螨类的制剂。  
3. **隔离与修剪**：受害重的枝叶修剪丢弃；问题株单独放置观察。  
4. **环境与营养**：提升散射光与通风；避免高氮速效肥；适度加湿降低红蜘蛛风险。

### 预防要点
新植株隔离1–2周；每周翻叶“体检”；避免长期喷黏性叶面光亮剂。坚持温和、连贯的控制策略，通常可在数周内清场。

# da:896
### 你看到的现象
叶片上出现白色或灰白水渍，干后留下斑点或雾状印记，摸上去无凸起；多见于光滑厚叶或深绿色叶面。

### 是什么
喷洒水或营养液干后留下的矿物质/表面活性剂残留，并非病斑。自来水硬度高时尤易出现。

### 是否属于正常现象
属于常见现象，不是疾病。仅影响观感，可通过清洁和换水源改善。

### 可能原因
- 硬水中的钙镁盐沉积；  
- 营养液/叶面肥浓度偏高或喷后未擦干；  
- 喷雾在强光下迅速蒸发，留下痕迹。

### 如何确认
- 残迹多沿水珠边缘呈环状或片状，不向周围扩展；  
- 叶背通常正常；  
- 用湿布轻擦可淡化或去除。

### 你可以做什么
1. **清洁**：软布蘸清水或稀释温和肥皂水擦拭；再用清水复擦。  
2. **改善水源**：使用过滤水、凉开水或低矿化度水；尽量避免硬水直接喷叶。  
3. **调整方式**：需要喷施时在**弱光/傍晚**进行，薄施少量；喷后轻拭大水珠。  
4. **长期方案**：更多以加湿器、托盘增湿代替直接喷叶；叶面肥改为根施或更低浓度。

### 预防要点
重在“源头换水、喷后轻拭”。不要把残留误判为真菌病，以免过度用药。

# da:1236
### 你看到的现象
新叶蜷卷、颜色偏浅或半透明，边缘尚未展开；叶面可能带有淡红/浅黄嫩色，几天后逐渐拉平。

### 是什么
新叶正在生长与展开的自然阶段。细胞壁尚未完全增厚，因此更柔软、更浅色。

### 是否属于正常现象
是自然现象，无需担心。只要核心生长点健康，新叶很快会舒展并转绿。

### 可能原因
- 正常生长；  
- 环境突变（温差、光照变化）会让新叶展开稍慢，但不影响健康。

### 如何确认
- 观察生长心：顶端有新芽不断顶出；  
- 新叶没有病斑或糜烂气味；  
- 1–2周内叶片逐步转深、变硬。

### 你可以做什么
1. **耐心与稳定**：提供明亮散射光，避免暴晒；保持22–28°C稳定温度。  
2. **适度水分**：维持基质微湿但不积水；新叶期不大水大肥。  
3. **不要强行掰开**：强行辅助展开易扯裂或伤及生长点。  
4. **轻度营养**：若已适应环境，可两周一次稀薄平衡肥。

### 预防要点
避免频繁搬动与忽冷忽热；新叶期更注重温柔管理。看到新生，就是最好的健康信号。

# da:907
### 你看到的现象
叶片无力下垂、整体发蔫，叶缘干焦、土壤轻而离盆壁；浇水后短时间内恢复挺立。

### 是什么
水分供应不足造成的暂时性萎蔫或慢性干旱。长久缺水会导致叶尖焦枯、落叶甚至根系受损。

### 是否属于正常现象
是真实问题，但通过正确补水与调整频率即可逆转。偶发一次无碍，长期反复需改管理。

### 可能原因
- 浇水量不足/频次偏少；  
- 基质疏水（干过头后遇水不易浸润）；  
- 盆土过小、蒸散量大；  
- 高温强光或风大导致蒸腾过强。

### 如何确认
- **手测**：插入指尖2–3厘米，明显干燥；  
- **称重**：盆体异常轻；  
- **浇后反应**：浇透20–60分钟内逐步回挺；  
- **叶色**：呈暗绿/灰绿而非黄斑类病症。

### 你可以做什么
1. **一次性补足**：分2–3次慢浇至盆底滴水，倒空托盘积水。  
2. **改良疏水土**：下浸吸水10–20分钟再沥干；或换入含珍珠岩/椰糠的透气基质。  
3. **调整节律**：记录盆土干至表层下2–3厘米再浇；夏季或风大时适度增加频率。  
4. **减轻蒸腾**：暂避正午强光，改善通风但避免直吹。  
5. **恢复后补肥**：待新芽稳定再薄肥，避免一次性高浓度。

### 预防要点
形成固定的“手测/称重”判断体系；对喜水植物用稍大盆或添加保水颗粒；炎夏上午浇，减少午后压力。

# da:899
### 你看到的现象
叶片发黄、软烂，基部或叶柄水渍状，盆土长期潮湿发酸，有霉味；新根少，老根发黑糜烂；偶见“时湿时干”后叶缘焦枯。

### 是什么
过量浇水或浇水极不均造成的水分胁迫。长期积水会缺氧致根腐；反复“淋湿—干透—再淋湿”也会损伤组织。

### 是否属于正常现象
是真实问题，需要纠正浇水与基质。若已出现根腐，应尽快处理。

### 可能原因
- 盆无排水孔/土过黏；  
- 低光低温下仍高频浇水；  
- 托盘长期存水；  
- 一次性浇太猛，随后又长时间断水。

### 如何确认
- **湿度计/手测**：盆心长期湿冷；  
- **根系**：脱盆可见黑褐、易拉断的烂根；  
- **气味**：土腥转臭；  
- **叶症**：下部叶黄垂软，上部新叶小且薄。

### 你可以做什么
1. **急救与整顿**：立即倒空托盘，移至通风明亮处；若疑似根腐，脱盆修根：剪除烂根、根部消毒（按说明），新土换盆。  
2. **优化基质与花盆**：使用疏松排水土（泥炭/椰糠+珍珠岩/松鳞），盆底加网防堵孔；盆不宜过大。  
3. **重建节律**：明亮处“见干见湿”，阴凉处“微干再浇”；每次浇至盆底出水即止。  
4. **均匀浇透**：环圈浇或两次分浇，避免“上湿下干”。  
5. **修复期管理**：暂停施肥，待新根/新叶出现再恢复低浓度。

### 预防要点
遵循“光照越低→浇水越少”；每次浇后倒空托盘；冬季低温时宁偏干不积水。

# da:909
### 你看到的现象

1. **立即遮阴降温**：加纱帘或后退位置；通风降热。  
2. **循序渐进**：2–3周逐步增加光照，先早晚阳光，后短时直射。  
3. **水分与护理**：早浇水、保持土微湿；严重灼伤叶可分期修剪。

### 预防要点
任何“加光”都要分阶段；耐阴植物避免长时直射；关注反光面与高温天气叠加风险。
