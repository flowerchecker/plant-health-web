# 欢迎使用 plant.health 文库（Wiki）

基于证据、实用的指南，帮助诊断植物问题并保持植物健康——涵盖害虫、传染性病害（真菌、细菌、病毒）、非生物胁迫（水分、光照、养分、温度）以及与问题相似的正常现象。

## 本库包含

- **病害：** 关于真菌、细菌和病毒病的详细说明。
- **害虫：** 常见害虫的信息。
- **非生物胁迫：** 非感染性问题（如灌溉过多/不足、光照胁迫）。
- **自然/无害的相似现象：** 如新叶抽生等正常阶段。

## 关于本库

条目对应 [kindwise](https://www.kindwise.com) 的 [plant.health](https://www.kindwise.com/plant-health) 产品中的类别。内容由大语言模型起草，并由植物健康专家审核。本库仅收录了 [plant.health](https://www.kindwise.com/plant-health) API 中 548 个类别中的 21 个精选问题。
