# 日灼伤

## 你看到的现象
叶片或果实受光面出现大片漂白、黄白灼斑，触感发脆；树皮或粗枝向阳面出现裂伤、晒裂。

## 是什么
强烈日辐射与高温共同造成的表皮灼伤（常称“日灼”）。多在晴天突升温或遮阴突然移除时发生。

## 是否属于正常现象
不属自然过程，但在夏季常见。适当遮阴与逐步适应可避免复发。

## 可能原因
- 正午直射时间过长；  
- 由室内荫处骤移至强光；  
- 反光面（白墙、玻璃）加强了照度与热量。

## 如何确认
- 受伤集中在向阳面；  
- 发生于光照突变1–3天内；  
- 与病斑不同，灼斑边界清晰、质地脆硬。

## 你可以做什么
1. **快速降热降光**：加遮阴、后退位置、开启通风。  
2. **分阶段适应**：2–3周逐步增加直射时长，先晨光后午前，再评估耐受。  
3. **护理**：受伤叶可保留充当“遮挡”，待新叶稳定后再修剪。树皮晒裂可涂白或用遮阳带。  
4. **水分管理**：保持根区湿润但不积水，清晨浇水帮助白天散热。

## 预防要点
春末夏初谨慎“升光”，强反射环境更要注意；耐阴植物长期不宜直晒。
