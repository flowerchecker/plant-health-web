# Vítejte v knihovně plant.health (Wiki)

Praktický  průvodce diagnostikou problémů rostlin — zahrnuje škůdce, infekční choroby (houby, bakterie, viry), abiotické poruchy (voda, světlo, živiny, teplota) i běžné, neškodné záměny.

## Co zde najdete

- **Choroby:** Podrobné popisy houbových, bakteriálních a virových chorob.
- **Škůdci:** Informace o běžných škůdcích.
- **Abiotické poruchy:** Neinfekční potíže (např. přemokření či nedostatečná zálivka, světelný stres).
- **Přirozené/neškodné záměny:** Normální fáze, např. rašící list.

## O této knihovně

Záznamy odpovídají třídám produktu [plant.health](https://www.kindwise.com/plant-health) od [kindwise](https://www.kindwise.com). Obsah vznikl s pomocí velkého jazykového modelu a byl zkontrolován odborníkem na zdraví rostlin. Knihovna pokrývá pouze 21 vybraných problémů z celkových 548 tříd v API [plant.health](https://www.kindwise.com/plant-health).
