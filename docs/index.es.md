# Bienvenidos a la biblioteca plant.health (Wiki)

Guías prácticas basadas en evidencia para diagnosticar problemas de las plantas y mantenerlas sanas — abarcan plagas, enfermedades infecciosas (hongos, bacterias, virus), trastornos abióticos (agua, luz, nutrientes, temperatura) y fenómenos normales que pueden confundirse con problemas.

## Qué incluye

- **Enfermedades:** Descripciones detalladas de enfermedades fúngicas, bacterianas y virales.
- **Plagas:** Información sobre plagas comunes.
- **Trastornos abióticos:** Problemas no infecciosos (p. ej., riego excesivo/insuficiente, estrés lumínico).
- **Similares naturales/inofensivos:** Etapas normales como una hoja emergente.

## Acerca de esta biblioteca

Las entradas corresponden a las clases del producto [plant.health](https://www.kindwise.com/plant-health) de [kindwise](https://www.kindwise.com). El contenido fue redactado con un modelo de lenguaje grande y revisado por un(a) especialista en sanidad vegetal. Esta biblioteca cubre solo 21 problemas seleccionados de un total de 548 clases en la API de [plant.health](https://www.kindwise.com/plant-health).
