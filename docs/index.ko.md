# plant.health 라이브러리(위키)에 오신 것을 환영합니다

식물 문제를 진단하고 건강을 유지하는 데 도움이 되는 근거 기반의 실용 가이드 — 해충, 전염성 병(곰팡이·세균·바이러스), 비생물적 스트레스(물, 빛, 영양, 온도), 그리고 문제처럼 보일 수 있는 정상 현상을 다룹니다.

## 구성

- **병해:** 곰팡이·세균·바이러스 병에 대한 자세한 설명.
- **해충:** 흔한 해충에 대한 정보.
- **비생물적 스트레스:** 비감염성 문제(예: 과도/부족한 관수, 광 스트레스).
- **자연적/무해한 유사 현상:** 새잎 전개와 같은 정상 단계.

## 이 라이브러리에 대하여

항목들은 [kindwise](https://www.kindwise.com)의 [plant.health](https://www.kindwise.com/plant-health) 제품의 클래스에 매핑됩니다. 콘텐츠는 대형 언어 모델로 초안이 작성되었고 식물 건강 전문가의 검토를 거쳤습니다. 이 라이브러리는 [plant.health](https://www.kindwise.com/plant-health) API의 총 548개 클래스 중 선택된 21개 이슈만을 다룹니다.
