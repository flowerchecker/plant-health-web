# 不当向叶丛中心浇水

## 你看到的现象
莲座或心叶中心积水，随后出现黑腐、软烂、伴有异味；叶心轻碰即脱。

## 是什么
在叶片呈莲座或紧凑心叶的植物上，从叶心灌水导致的积水性腐烂。常见于多肉、凤梨科、非洲堇等结构紧凑品种。

## 是否属于正常现象
养护不当导致的真实问题，需要立刻修正浇水方式。

## 可能原因
- 直接向叶心/莲座中心浇水；  
- 夜间或低温时叶心长期潮湿；  
- 通风差，水分难以蒸发。

## 如何确认
- 腐烂多从心部向外扩展，伴异味；  
- 叶心发黑易脱，外围叶相对完好；  
- 多发生在一次或几次“从中间浇水”之后。

## 你可以做什么
1. **立刻排水干燥**：用纸巾或棉签吸干叶心积水；移至通风处。  
2. **改为边浇或底浇**：沿盆沿慢浇，或托盘下吸水后倒掉余水。  
3. **必要时处理腐烂**：剪除黑腐组织，保留健康部分；多肉可挽救性扦插。  
4. **改善环境**：增强通风、加温、避免夜间浇水。

## 预防要点
牢记“叶心常干、土略湿”；浇后检查是否有水滞留在叶杯或中心。
