# 除草剂损害

**你看到的現象**  
鄰近曾使用除草配方或處理草皮後，植株出現畸形：新葉縮皺、杯狀、細長披針狀，葉脈彎曲。

**是什麼**  
除草劑飄散、器具殘留或誤觸造成的非目標藥害。

**是否屬於健康問題**  
是，但多需時間觀察與恢復；受害新葉難以逆轉，重點在後續新生是否恢復正常。

**可能原因**  
- 風大時段噴灑導致飄移。  
- 共用噴壺未徹底清洗或標示不清。  
- 土壤/覆蓋物帶入殘留。

**如何確認**  
- 發生時間與周遭除草作業相符。  
- 同一風向的一排植株受害較重。

**建議步驟**  
1) 立即遠離來源、加強通風與灌水稀釋（勿造成積水）。  
2) 停止一切藥劑，連續觀察 4–8 週，新梢若逐步恢復正常形態代表已度過。  
3) 器具分開使用並徹底清洗；嚴重者換新介質與盆。

**預防小撇步**  
家中若需除草，選無風時段且遠離盆栽；噴具清楚標示「除草專用」與「園藝防治專用」分開。
