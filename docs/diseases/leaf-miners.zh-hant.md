# 潜叶虫

**你看到的現象**  
葉片出現蛇行白色隧道，末端可見小黑點或隆起；美觀受影響，但通常不致命。

**是什麼**  
潛葉蠅/潛葉蛾幼蟲在葉內層取食形成的蟲道。

**是否屬於健康問題**  
輕中度；及早處理即可控。

**可能原因**  
- 成蟲在葉面產卵，幼蟲孵化後在葉內取食。  
- 陽台、戶外通風處較常見。

**如何確認**  
將葉對光觀察隧道；以指腹輕壓隧道末端常可觸到幼蟲。

**建議步驟**  
1) 物理移除：剪除受害重的葉；或沿隧道末端捏死幼蟲。  
2) 隔離：減少擴散至其他植株。  
3) 防治：必要時依標示使用園藝皂/苦楝油，連續 2–3 次；戶外加黃板誘殺成蟲。  
4) 復健：提升光照與通風，加速長出新葉。

**預防小撇步**  
新芽期最脆弱，定期巡葉；保持環境整潔與適度乾燥。
