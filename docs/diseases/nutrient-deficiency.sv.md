# brist på näringsämnen.

**Det du ser**  
Bleka blad, gula nerver eller jämn gulning, svag tillväxt och små blad. Vissa arter får rödaktiga stjälkar.

**Beskrivning**  
Växten saknar lättillgängliga näringsämnen i rätt balans eller kan inte ta upp dem (pH, rotskada). Vanligast är brist på kväve (allmän gulning), järn (ljus bladskiva + gröna nerver i nya blad) eller magnesium (gulning mellan nerver i äldre blad).

**Är det ett problem eller naturligt?**  
Odlingsproblem – går oftast att vända med balanserad näring och frisk rotmiljö.

**Vanliga orsaker**  
- Otillräcklig gödning under aktiv tillväxt.  
- Oregelbunden vattning som skadar rötter → sämre upptag.  
- Fel pH eller saltuppbyggnad i jorden.

**Så bekräftar du**  
- Mönstret: nya vs. gamla blad drabbas olika beroende på ämne.  
- Uteslut ljusbrist/övervattning först.  
- Växten svarar inom veckor på komplett, svag näring.

**Gör så här nu**  
1) Starta med svag komplett näring (¼–½ dos) varannan vattning.  
2) Spola igenom krukan med vatten vid misstänkt saltsamling.  
3) Justera vattning och jord för att gynna friska rötter.  
4) Vid tydlig järnkloros (nya blad ljusa, nerver gröna): prova järnkelat.  
5) Följ upp – ny tillväxt ska bli grönare och större.

**Förebygg framöver**  
- Regelbunden, svag gödning under ljusa månader; minska vintertid.  
- Årlig omplantering eller toppa med frisk jord.

**När det räcker**  
Gamla gula blad blir inte gröna igen – bedöm förbättringen på nya blad.
