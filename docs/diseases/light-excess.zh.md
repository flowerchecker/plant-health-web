# 多余的阳光

## 你看到的现象
叶片褪色、发白或出现黄白斑，表皮发脆；严重时出现灼斑、干枯；新叶偏小、紧凑但无光泽。

## 是什么
光照强度过高或暴晒时间过长造成的光伤。短时间突遇强光（尤其正午直射）最易发生。

## 是否属于正常现象
不正常，但常见于春夏换季、搬家或补光不当。多数情况下通过遮阴与逐步适应可恢复。

## 可能原因
- 突然移到南向窗台无遮挡位置；  
- 春末夏初日照增强；  
- 植物灯距离过近或功率过高。

## 如何确认
- 灼斑多出现在受光面，与叶脉关系不明显；  
- 同株靠窗一侧更重；  
- 多发生在光照骤变后1–3天内。

## 你可以做什么
1. **立即降光**：加纱帘/百叶，或后退30–100厘米；提高灯距或缩短时长。  
2. **循序适应**：每日增加30–60分钟光照，2–3周过渡到目标强度。  
3. **水分与通风**：维持微湿、避免叶面长时滞水；加强空气流通。  
4. **受损叶**：轻度灼斑可保留（仍可光合）；严重干枯可分次修剪。

## 预防要点
所有“升光”都要分阶段：先散射、再斜射、后少量直射。补光设备遵循“低强度、长时长”更安全。
