# 农药损伤
### 你看到的现象
喷药后不久出现叶片失绿斑、边缘灼伤、畸形、落叶；新芽被抑制，叶面出现不规则水渍样斑驳。

### 是什么
药剂对植物产生的非目标伤害（药害）。与病虫害不同，时间上常与喷施行为紧密相关，且多在喷后1–7天内显现。

### 是否属于正常现象
是真实问题。多数轻度药害可自行恢复，重度需要修剪与耐心养护。

### 可能原因
- 浓度过高、喷布过密；  
- 高温、强光、封闭环境下喷施；  
- 混配不当（如油剂叠加刺激）；  
- 品种本身敏感。

### 如何确认
- 回想喷施记录（剂型、剂量、时间、天气）；  
- 症状集中在受药叶面，并在同一时间段出现；  
- 同一风向/受光侧更明显。

### 你可以做什么
1. **当即冲洗**：发现异常24小时内，用清水充分冲洗叶面，减少残留。  
2. **移至温和环境**：明亮散射光、良好通风，避免强光与高温。  
3. **修剪与等待**：去除严重灼伤叶片；暂停施肥与再次喷药，待新芽长出再逐步恢复管理。  
4. **记录并调整**：下次严格按说明“低浓度、先试喷、避高温与强光”。

### 预防要点
先小范围试喷48小时观察；混配前查兼容性；喷后数小时内避免直射与密闭。
