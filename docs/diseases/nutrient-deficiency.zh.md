# 营养缺乏

## 你看到的现象
叶片泛黄或褪绿，叶脉仍绿（缺铁/镁常见）；老叶先黄（缺氮/钾），新叶先黄（缺铁）；生长缓慢、开花少。

## 是什么
长期供应不足或吸收受阻导致的矿质元素缺乏。并非单一配方能一劳永逸，需要结合基质、浇水与光照综合判断。

## 是否属于正常现象
真实问题，但多数可通过**薄肥勤施**与改善根区环境纠正。

## 可能原因
- 长期不施肥或基质贫瘠；  
- 过度浇水导致养分流失；  
- pH不合适影响吸收（偏碱常见缺铁）；  
- 根系受损，吸收受限。

## 如何确认
- **部位判别**：老叶先黄多为缺氮/钾；新叶先黄多为缺铁/锰；边缘灼枯可能缺钾。  
- **环境排查**：若同时存在低光/涝害，先矫正环境再施肥。  
- **对照恢复**：按计划补肥后，**新叶**转绿、生长提速即为佐证（旧叶不一定恢复）。

## 你可以做什么
1. **从温和开始**：选用平衡型水溶肥，按说明1/4–1/2倍浓度，每2–4周一次。  
2. **针对性补充**：叶脉绿而叶肉黄→补铁剂或酸性营养液；老叶普黄→适度补氮；叶缘焦枯→补钾并检查浇水失衡。  
3. **改良土与水**：使用含缓释肥的通气基质；必要时替换部分老土；硬水环境适度酸化水源。  
4. **避免过量**：切勿浓肥猛施；施后充分淋清水一次，避免盐分堆积。

## 预防要点
建立“轻量、规律”的施肥节奏；每季检查盆土盐渍与pH；施肥与良好光照、健康根系配套，效果才稳定。
