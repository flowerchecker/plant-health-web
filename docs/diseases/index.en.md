# Welcome to the plant.health library (Wiki)

Evidence-based, practical guides for diagnosing plant problems and keeping plants healthy—covering pests, infectious diseases (fungi, bacteria, viruses), abiotic disorders (water, light, nutrients, temperature), and normal look-alikes.

## What's inside

- **Diseases:** Detailed descriptions of fungal, bacterial, and viral diseases.
- **Pests:** Information on common pests.
- **Abiotic disorders:** Non-infectious issues (e.g., over-/under-watering, light stress).
- **Natural/benign look-alikes:** Normal stages like an emerging leaf.

## About this library

Entries map to classes in [kindwise](https://www.kindwise.com)’s [plant.health](https://www.kindwise.com/plant-health) product. Content was drafted with a large language model and reviewed by a plant-health expert. This library covers 21 selected issues out of 548 classes in the [plant.health](https://www.kindwise.com/plant-health) API.
