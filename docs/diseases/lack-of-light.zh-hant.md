# 缺光

**你看到的現象**  
枝條徒長、節間拉長、葉色偏淡或偏黃，新葉小而稀疏，植株明顯向光。

**是什麼**  
光線不足造成的生長失衡與葉綠素不足。

**是否屬於健康問題**  
是，但透過補光或移位可顯著改善。

**可能原因**  
- 距窗過遠、窗外有遮擋。  
- 冬季日照短或天候長期陰沉。

**如何確認**  
觀察陰影是否清晰：模糊陰影通常代表弱光。多數室內植物至少需要「明亮散射光」。

**建議步驟**  
1) 逐步移近窗邊（東/西/南窗 0.5–1.5 公尺內）。  
2) 使用全光譜 LED 植物燈，補光 10–12 小時/日；燈距 20–40 公分（依功率調整）。  
3) 修剪徒長枝促進分枝，並每月旋轉花盆 90°。

**預防小撇步**  
固定位置後避免頻繁搬動；依季節與窗向調整距離。
