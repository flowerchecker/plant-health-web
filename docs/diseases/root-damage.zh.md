# 根系损伤
### 你看到的现象
上部萎蔫或黄化，但盆土并不干；生长停滞；脱盆见根发黑、空心或断裂，或新根极少。

### 是什么
根系遭受物理、化学或病原损伤导致的功能丧失。根是水分与养分入口，一旦受损，地上部迅速异常。

### 是否属于正常现象
真实问题，需尽快处理与复壮。

### 可能原因
- 过度浇水→缺氧→根腐；  
- 换盆/搬运时拉扯折断；  
- 高盐/高肥烧根；  
- 低温冻伤；  
- 土传病害或虫害（如蛴螬）。

### 如何确认
- **脱盆检查**：健康根白/奶黄、坚韧；病根黑褐、糜烂、有臭味。  
- **盆底与盆壁**：有积水、苔藓或盐分结晶。  
- **时间线**：在一次换盆或大水后不久症状加剧。

### 你可以做什么
1. **修根与消毒**：剪除腐烂与空心根；清水冲净，按说明使用根部消毒剂。  
2. **更换基质**：使用疏松透气、排水良好的新土；盆底加网与排水层。  
3. **控水与缓苗**：盆土保持微湿，避免再次大水；放置明亮散射光、通风处。  
4. **促发新根**：2–3周后视恢复，少量多次补稀薄营养，或用生根剂（按说明）。  
5. **排查虫害**：发现幼虫及时清除，必要时用对应药剂土灌。

### 预防要点
换盆托住土球与根颈，避免剧烈震动；肥料“少量多次”；冬季低温把控浇水，宁干勿涝。
