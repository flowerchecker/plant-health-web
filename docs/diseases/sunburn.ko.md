# 일소

## 무엇을 보고 있나요?
강한 빛을 받은 면에 희끗하거나 갈색의 납작한 반점이 생깁니다. 위치 이동 후 급격히 나타나는 일이 많습니다.

## 무엇인가요? 실제 문제인가요?
잎에서 발생한 **햇볕 데임(일소)** 입니다. 대개 미관상의 문제이며, 원인 제거 후 더 번지지 않습니다.

## 가능한 원인
- 여름 남향 창의 강한 직사광선  
- 어두운 실내에서 갑자기 야외 베란다로 이동  
- 유리·밝은 벽에서 반사되는 강광

## 확인 방법
- **노출된 표면**에만 규칙적인 모양으로 생깁니다(창살·그림자 모양과 일치).  
- 원인 제거 후 크기가 더 커지지 않습니다.

## 지금 무엇을 해야 하나요?
- 밝은 간접광으로 옮기고, 썩은 부분만 최소한으로 정리합니다.  
- 회복을 돕기 위해 물주기는 균형 있게 유지하되 과습을 피합니다.  
- 더 강한 빛에 적응시키려면 **10–14일**에 걸쳐 점진적으로 노출을 늘립니다.

## 예방/관리
- ‘서서히 적응’이 최선의 예방입니다.  
- 얇은 커튼·차광막, 창에서 약간 떨어진 위치를 활용하세요.
