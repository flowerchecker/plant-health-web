# 不當向葉叢中心澆水

**你看到的現象**  
葉心（葉簇中心）長期積水後，心部發黑腐爛，年輕葉片易折、易軟爛；常見於貼地生長的蓮座型植物。

**是什麼**  
從上方將水倒進葉心或噴葉，使水滯留於冠心，造成腐敗與繼發感染。

**是否屬於健康問題**  
是，但屬操作方式可改善的問題。

**可能原因**  
- 直接向葉心澆水或夜間噴霧使其久濕。  
- 通風弱、陰雨連日導致不易乾燥。

**如何確認**  
分開葉簇觀察心部：是否濕黏、有異味或黑化；觸碰是否易塌。

**建議步驟**  
1) 立即停止向葉心供水，並以紙巾吸乾積水。  
2) 改以「沿盆緣入土」或「底部吸水」法，並加強通風與日間光照。  
3) 若已腐爛，修除軟爛組織並撒少量木炭粉，保持乾爽觀察；嚴重時分株保留健康部分。

**預防小撇步**  
澆水讓水直接進土；噴霧僅作短暫增濕且需 1–2 小時內乾；雨季特別留意心部乾燥。
