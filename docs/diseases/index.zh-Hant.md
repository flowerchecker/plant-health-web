# 歡迎使用 plant.health 資料庫（Wiki）

以證據為基礎的實用指南，協助診斷植物問題並維持植物健康——涵蓋害蟲、傳染性病害（真菌、細菌、病毒）、非生物逆境（水分、光照、養分、溫度）以及與問題相似的正常現象。

## 內容包含

- **病害：** 關於真菌、細菌與病毒病的詳細說明。
- **害蟲：** 常見害蟲的資訊。
- **非生物逆境：** 非感染性問題（例如灌溉過多/不足、光照壓力）。
- **自然/無害的近似現象：** 如新葉展開等正常階段。

## 關於本資料庫

條目對應 [kindwise](https://www.kindwise.com) 的 [plant.health](https://www.kindwise.com/plant-health) 產品之類別。內容由大型語言模型撰寫，並經植物健康專家審閱。本資料庫僅收錄 [plant.health](https://www.kindwise.com/plant-health) API 中 548 個類別裡精選出的 21 個問題。
