# 농약 피해

**무엇을 보고 있나요?**  
약제 살포 후 잎에 갈변·희끗한 반점, 새잎의 말림·뒤틀림이 나타납니다.

**무엇인가요? 실제 문제인가요?**  
농도·시간·혼합이 맞지 않아 생긴 **약해(약제로 인한 손상)**입니다.

**가능한 원인**  
- 권장 농도보다 진하게 사용  
- 강한 햇빛·고온에서 살포  
- 짧은 간격의 반복 처리, 서로 맞지 않는 약제 혼용

**확인 방법**  
- 살포 후 **24–72시간** 안에, 처리한 잎에만 증상이 주로 나타납니다.  
- 해충 활동이 보이지 않는데 손상만 있다면 약해 가능성이 큽니다.

**지금 무엇을 해야 하나요?**  
- 미지근한 물로 잎 표면을 씻어 잔여물을 줄입니다.  
- 며칠간 반그늘에서 회복하도록 두고 스트레스를 최소화합니다.  
- 2주간 추가 처리를 멈춘 뒤, 필요 시 한 장에 소량 테스트 후 낮은 농도로 저녁 시간에 살포합니다.

**예방/관리**  
- 라벨 지시를 정확히 따르고 **정확한 계량**을 습관화하세요.  
- 새 약제·혼합은 항상 **부분 테스트** 후 확대합니다.
